# پیامک من (Payamak) — نسخه ۲

مدیریت‌کننده‌ی پیامک اندروید با Kotlin + Jetpack Compose (Material 3) + Room + Paging 3.

## امکانات
**پایه**
- گفتگو برای هر شماره/مخاطب، تاریخ شمسی، جستجو با هایلایت، بارگذاری تکه‌تکه (بدون هنگ)
- ارسال معمولی و زمان‌دار، دو سیم‌کارت، گزارش ارسال و تحویل
- مسدودسازی تبلیغات با فهرست قابل ویرایش (پیش‌شماره، شماره‌ی دقیق، Regex، عبارت در متن) و ابزار آزمایش
- فونت (وزیرمتن، شبنم، نسخ، امیری)، اندازه‌ی نوشته، پوسته‌ی روشن/تاریک

**جدید در نسخه ۲**
- **نقش «برنامه‌ی پیش‌فرض پیامک»**: دریافت و نوشتن در Provider سیستم، حذف واقعی، مسدودسازی بدون اعلان، «پاسخ با پیام» پس از رد تماس، باز شدن از لینک‌های `sms:` و اشتراک‌گذاری متن
- **MMS**: دریافت و نمایش تصویر، ارسال یک یا چند تصویر (فشرده‌سازی خودکار)، نمایش MMSهای قبلی گوشی
- **اعلان‌ها** با دکمه‌ی پاسخ سریع (Inline Reply)، «خوانده شد» و «کپی کد»
- **تشخیص کد تأیید (OTP)** و کپی با یک ضربه (در حباب پیام و اعلان)
- سنجاق‌کردن و بایگانی گفتگوها، علامت‌گذاری همه به‌عنوان خوانده
- عملیات روی پیام: کپی، ارسال به شخص دیگر، حذف؛ مسدودکردن شماره از داخل گفتگو
- پیام‌های آماده (قالب) با دکمه‌ی ⚡
- انتخاب گیرنده از مخاطبین
- پشتیبان‌گیری و بازیابی پیامک‌ها (JSON)

## دریافت APK با GitHub
1. محتوای پوشه را روی یک مخزن GitHub (شاخه‌ی main) push کنید.
2. تب **Actions ← Build APK** اجرا می‌شود؛ APK را از **Artifacts** بردارید.
3. برای انتشار: `git tag v2.0.0 && git push --tags` تا APK در Releases قرار بگیرد.

ساخت محلی: `gradle wrapper --gradle-version 8.9` و `./gradlew assembleDebug` (JDK 17).

## نکات مهم
- اندروید ۱۳+ و نصب مستقیم APK: «اطلاعات برنامه ← ⋮ ← Allow restricted settings» را بزنید، سپس دسترسی‌ها را بدهید.
- برای پیش‌فرض‌کردن: تنظیمات ← «پیش‌فرض‌کردن» (یا بنر بالای لیست گفتگوها).
- **MMS**: ارسال/دریافت فقط در نقش پیش‌فرض کار می‌کند و به APN/MMS اپراتور و داده‌ی موبایل نیاز دارد. این بخش با PDUهای استاندارد OMA نوشته شده ولی روی همه‌ی اپراتورها آزمایش نشده است؛ MMSهای دریافتی در پایگاه‌داده‌ی خود برنامه ذخیره می‌شوند (نه جدول MMS سیستم). MMS ارسالی بدون SMIL و با Content-Type «multipart/mixed» ساخته می‌شود.
- ارتقا از نسخه ۱ بدون از دست رفتن قانون‌های مسدودی و پیام‌های زمان‌بندی‌شده انجام می‌شود (Migration ۱←۲).
- فهرست پیش‌فرض سرشماره‌های تبلیغاتی فقط نمونه است؛ برخی پیامک‌های خدماتی بانک‌ها هم ممکن است با ۳۰۰۰ شروع شوند.
- امضای release با کلید debug است؛ برای انتشار عمومی کلید اختصاصی بسازید.

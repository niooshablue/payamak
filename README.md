# پیامک من (Payamak) — نسخه ۲٫۱

مدیریت‌کننده‌ی پیامک اندروید با Kotlin + Jetpack Compose (Material 3) + Room + Paging 3.

## امکانات
**پایه**
- گفتگو برای هر شماره/مخاطب، تاریخ شمسی، جستجو با هایلایت، بارگذاری تکه‌تکه (بدون هنگ)
- ارسال معمولی و زمان‌دار، دو سیم‌کارت، گزارش ارسال و تحویل
- مسدودسازی تبلیغات با فهرست قابل ویرایش (پیش‌شماره، شماره‌ی دقیق، Regex، عبارت در متن) و ابزار آزمایش
- فونت (وزیرمتن، شبنم، نسخ، امیری)، اندازه‌ی نوشته، پوسته‌ی روشن/تاریک

**نسخه ۲٫۱**
- لیست گفتگوها با یک جدول خلاصه ساخته می‌شود (Room + Paging 3) و حتی با ده‌ها هزار پیامک آنی باز می‌شود؛ پیام‌های هر گفتگو هم بلافاصله با ورود به چت نمایش داده می‌شوند. نام مخاطبین یک‌بار در حافظه بارگذاری می‌شود.
- نقش «برنامه‌ی پیش‌فرض پیامک»: نوشتن در Provider سیستم، حذف واقعی، مسدودسازی بدون اعلان، اعلان با پاسخ سریع، «پاسخ با پیام» پس از رد تماس
- جستجو در پیام‌های یک گفتگو، «جزئیات پیام»، «افزودن به مخاطبین» برای شماره‌های ناشناس
- نمونه الگوهای آماده‌ی مسدودسازی (شماره و متن، شامل Regex) و دکمه‌ی «بررسی و مسدودکردن تبلیغات قبلی» در تنظیمات
- «گزارش ارسال و تحویل» در تنظیمات
- تشخیص و کپی کد تأیید، سنجاق/بایگانی، پیام‌های آماده، پشتیبان‌گیری JSON، انتخاب از مخاطبین
- MMS و پیوست فایل پشتیبانی نمی‌شود (پیامک‌های MMS دریافتی نادیده گرفته می‌شوند)

## دریافت APK با GitHub
1. محتوای پوشه را روی یک مخزن GitHub (شاخه‌ی main) push کنید.
2. تب **Actions ← Build APK** اجرا می‌شود؛ APK را از **Artifacts** بردارید.
3. برای انتشار: `git tag v2.0.0 && git push --tags` تا APK در Releases قرار بگیرد.

ساخت محلی: `gradle wrapper --gradle-version 8.9` و `./gradlew assembleDebug` (JDK 17).

## نکات مهم
- اندروید ۱۳+ و نصب مستقیم APK: «اطلاعات برنامه ← ⋮ ← Allow restricted settings» را بزنید، سپس دسترسی‌ها را بدهید.
- برای پیش‌فرض‌کردن: تنظیمات ← «پیش‌فرض‌کردن» (یا بنر بالای لیست گفتگوها).
- ارتقا از نسخه‌های قبلی بدون از دست رفتن قانون‌های مسدودی و پیام‌های زمان‌بندی‌شده انجام می‌شود (Migration ۱←۲←۳).
- فهرست پیش‌فرض سرشماره‌های تبلیغاتی فقط نمونه است؛ برخی پیامک‌های خدماتی بانک‌ها هم ممکن است با ۳۰۰۰ شروع شوند.
- امضای release با کلید debug است؛ برای انتشار عمومی کلید اختصاصی بسازید.
